## 🔍 Technology Stack

- **Frontend:** Next.js 16, React, TypeScript, Tailwind CSS
- **Authentication:** NextAuth.js v5 (Google + Microsoft OAuth)
- **Database Options:** Vercel Postgres, MongoDB, Supabase
- **Deployment:** Vercel, Azure Static Web Apps
- **Storage:** Google Drive API (optional)
