## 🛠 Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript 5.9, Tailwind CSS 3.4
- **Auth:** NextAuth.js v5 (Google + Microsoft OAuth)
- **Database:** Vercel Postgres, MongoDB, or Supabase
- **Charts:** Recharts 3.5
- **Deployment:** Vercel, Azure Static Web Apps
